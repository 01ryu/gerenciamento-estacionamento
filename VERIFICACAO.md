# Verificação do exemplo da disciplina

## Material utilizado

- ReleaseFim_Exemplo_ReactNative.pdf.
- Portal_Academico_R05_Produto_Funcional_ExpoSDK57.zip.

Os materiais foram fornecidos pelo usuário para a atividade. O código do professor não foi publicado como se fosse o aplicativo de estacionamento.

## Ambiente

- Expo SDK 57, versão declarada 57.0.21.
- React Native 0.86.0 e React 19.2.3.
- Instalação de dependências com pnpm.
- Servidor Expo em modo web, porta local 8081.
- Navegador Microsoft Edge, janela de 430 x 1.100 pixels.

## Resultado observado

- As telas Início, Disciplinas, Atividades e Perfil abriram e exibiram os dados simulados.
- No painel, concluir uma atividade alterou o progresso de 0% para 25%.
- Reiniciar o contador restaurou o progresso para 0%.
- Foram feitas capturas das quatro telas, incluídas no relatório PDF.

## Limites da verificação

Não foi realizada validação em aparelho Android ou iOS nem gerado APK. A verificação refere-se ao exemplo acadêmico em ambiente web, não à implementação do aplicativo de estacionamento.
